# IDiME
このリポジトリは、情報系用語変換辞書「IDiME」の配布リポジトリです。

IDiMEはオープンソースの情報系用語変換辞書です。オープンソースの日本語IME、[Meltype](https://github.com/yksr-melt/Meltype)の内蔵辞書向けに作成されました。しかし、その他の用途でもご利用になれます。
この辞典は、一般社団法人 情報処理学会 情報入試委員会が作成・公開している、高等学校の検定済教科書に基づく用語集「[情報科全教科書用語リスト第2版](https://www.ipsj.or.jp/topics/20261022_wordlist-v2.html)」（CC BY-SA 4.0）をベースに、作成・改変・追加したものです。 情報科全教科書用語リストがCC BY-SA 4.0であることから、それを継承し、CC BY-SA 4.0の辞書となります。
