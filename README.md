# IDiME
このリポジトリは、医学医療用語変換辞書「[DMiME](https://github.com/c-colloid/DMiME)」にインスパイヤを受けて作成された、情報系用語変換辞書「**IDiME**」の配布リポジトリです。

IDiMEはオープンソースの情報系用語変換辞書です。オープンソースの日本語IME、[Meltype](https://github.com/yksr-melt/Meltype) の内蔵辞書向けに作成されましたが、通常のユーザー辞書としてもご利用いただけます。
この辞典は、一般社団法人 情報処理学会 情報入試委員会が作成・公開している、高等学校の検定済教科書に基づく用語集「[情報科全教科書用語リスト第2版](https://www.ipsj.or.jp/topics/20261022_wordlist-v2.html)」（CC BY-SA 4.0）をベースに、作成・改変・追加したものです。 情報科全教科書用語リストのライセンス (CC BY-SA 4.0) を継承し、この辞書のライセンスも CC BY-SA 4.0 となります。
